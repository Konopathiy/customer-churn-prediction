# Прогнозирование оттока клиентов

Учебный проект по классификации: предсказать, уйдёт ли клиент телеком-компании, и объяснить, какие факторы связаны с оттоком.

## Вопрос проекта

**Какие клиенты с высокой вероятностью откажутся от услуг и что компания может сделать, чтобы их удержать?**

## Данные

Публичный датасет **Telco Customer Churn** (IBM Sample Data Sets).  
Скачай `WA_Fn-UseC_-Telco-Customer-Churn.csv` и положи его в папку `data/telco_churn.csv`.

Основные поля:

- `customerID` — идентификатор клиента;
- `tenure` — сколько месяцев клиент пользуется услугами;
- `Contract` — тип контракта;
- `MonthlyCharges` — ежемесячный платёж;
- `TotalCharges` — общая сумма платежей;
- `Churn` — целевая переменная: `Yes`, если клиент ушёл.

## Что сделано

- Загрузка и первичный осмотр данных
- Обработка пропусков и преобразование типов
- EDA: распределение оттока, зависимость от контракта, срока обслуживания и платежей
- Кодирование категориальных признаков
- Стратифицированное разделение на train/test
- Обучение Logistic Regression и Random Forest
- Оценка моделей по precision, recall, F1 и ROC-AUC
- Построение confusion matrix и ROC-кривых
- Анализ важности признаков
- Выводы и бизнес-рекомендации

## Как запустить

1. Установи Python 3.10+.
2. Создай виртуальное окружение:

```bash
python -m venv .venv
```

3. Активируй его:

Windows:

```bash
.venv\Scripts\activate
```

macOS / Linux:

```bash
source .venv/bin/activate
```

4. Установи зависимости:

```bash
pip install -r requirements.txt
```

5. Положи датасет в `data/telco_churn.csv`.
6. Запусти Jupyter:

```bash
jupyter notebook
```

7. Открой `notebooks/churn_analysis.ipynb` и выполни все ячейки.

## Streamlit-приложение

После запуска ноутбука можно обучить и сохранить модель, а затем запустить приложение:

```bash
streamlit run app/app.py
```

Приложение позволяет ввести параметры клиента и получить вероятность оттока.

## Ограничения

- Данные синтетические/учебные и не описывают конкретную компанию.
- Модель показывает связь признаков с оттоком, но не доказывает причинность.
- Порог классификации нужно подбирать под бизнес-задачу: важнее не пропустить уходящего клиента или не беспокоить лояльного.
- Результаты не являются готовым бизнес-решением.
